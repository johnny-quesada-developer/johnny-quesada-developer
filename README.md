# Johnny Esteban Quesada

Senior full-stack engineer and open-source author based in Alicante, Spain. I work on React, Angular, TypeScript, Node.js, C#/.NET, application architecture, performance, and developer tooling.

My projects focus on making state management, asynchronous work, and collection processing easier to understand and use.
